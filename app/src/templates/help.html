Todo API

Reference documentation for all available endpoints.

POST /todos

Create a new todo item.

Request Body (JSON)

FieldTypeRequiredConstraints
titlestringYes 1–200 characters, must not be blank
descriptionstringNo 1–1000 characters when provided

Response Codes

CodeMeaning
201 Created Todo item created successfully. Returns the new item as JSON.
400 Bad Request Request body is missing or not valid JSON.
422 Unprocessable Entity Validation failed (e.g. missing title, blank title, or title too long).
GET /todos

Retrieve all todo items, ordered by creation time ascending.

Request Body

None — no request body required.

Response Codes

CodeMeaning
200 OK Returns a JSON array of all todo items (empty array [] when none exist).
500 Internal Server Error Database unavailable or unexpected server error.
GET /todos/<id>

Retrieve a single todo item by its integer ID.

Request Body

None — no request body required.

Response Codes

CodeMeaning
200 OK Returns the matching todo item as JSON.
404 Not Found No todo item exists with the given ID.
PUT /todos/<id>

Update one or more fields of an existing todo item. All body fields are optional.

Request Body (JSON)

FieldTypeRequiredConstraints
titlestringNo 1–200 characters, must not be blank
descriptionstringNo 1–1000 characters when provided
completedbooleanNo Must be true or false

Response Codes

CodeMeaning
200 OK Todo item updated successfully. Returns the updated item as JSON.
400 Bad Request Request body is missing or not valid JSON.
404 Not Found No todo item exists with the given ID.
422 Unprocessable Entity Validation failed (e.g. blank title, title too long, or non-boolean completed).
DELETE /todos/<id>

Permanently delete a todo item by its integer ID.

Request Body

None — no request body required.

Response Codes

CodeMeaning
204 No Content Todo item deleted successfully. No response body.
400 Bad Request The provided ID is not a valid integer.
404 Not Found No todo item exists with the given ID.

Todo App API — all responses use JSON unless noted otherwise.
